Categories

Categories are automatically inferred when you add a repo. A low-confidence result goes into review rather than a guessed category.

Add a GitHub repository

No category dropdown. Atlas reads the GitHub description, topics and README. If GitHub limits requests, you can save the link as unverified and refresh later.

Add any web link

GitHub URLs become repositories. Other websites are saved as research sources, automatically categorized from their URL and title. Browser restrictions prevent reliable automatic reading of arbitrary webpages without a backend.

Add screenshots and images

Supports PNG, JPG and other browser-readable images, up to 12 MB each. Screenshots can be scanned locally for GitHub links.

Image-to-text uses optional browser OCR (Tesseract.js loaded from a public CDN only when needed). The image is stored locally; browser OCR requires internet to load its engine. Review links before adding.
